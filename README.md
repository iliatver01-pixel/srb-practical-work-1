
# Практическая работа №1 — Системы реального времени

Программа анализирует набор задач системы реального времени. Она рассчитывает запас времени до дедлайна, проверяет условие `C ≤ D`, определяет тип дедлайна и критическую задачу, вычисляет коэффициент загрузки процессора и выводит характеристики системы.

## Требования

- Python 3.10 или новее.
- Git — для клонирования репозитория через командную строку.
- Дополнительные библиотеки Python не нужны.

## Установка

1. Установите Python с официального сайта: https://www.python.org/downloads/
2. Откройте терминал и выполните:

```powershell
git clone https://github.com/iliatver01-pixel/srb-practical-work-1.git
cd srb-practical-work-1
```

## Запуск

Из корневой папки проекта выполните:

```powershell
py src/main.py
```

По умолчанию программа использует данные из `data/tasks.csv`.

Можно указать другой CSV-файл, количество процессоров и наличие сети:

```powershell
py src/main.py --data data/tasks.csv --cpu 4 --network no
```

Параметры:
- `--data` — путь к CSV-файлу с задачами.
- `--cpu` — количество процессоров (по умолчанию `1`).
- `--network` — наличие сети: `yes` или `no` (по умолчанию `no`).

## Формат входных данных

Файл CSV должен содержать столбцы `name,hardness,C,D,T`:

- `name` — название задачи.
- `hardness` — класс задачи: `жёсткое` или `мягкое`.
- `C` — время выполнения задачи.
- `D` — относительный дедлайн.
- `T` — период задачи.

Все временные значения задаются в миллисекундах.

## Проверка тестов

Чтобы запустить автоматические тесты из корневой папки проекта:
