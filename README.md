# Практическая работа №1 — СРВ

## Требования
- Python 3.10 или новее
- Дополнительные библиотеки не нужны

## Запуск
Из корневой папки проекта:

```bash
python src/main.py
```

Параметры:
- `--data data/tasks.csv` — путь к CSV с задачами
- `--cpu 1` — число процессоров
- `--network no` — наличие сети (`yes`/`no`)

Пример многопроцессорной системы без сети:
```bash
python src/main.py --cpu 4 --network no
```

Пример системы с сетью:
```bash
python src/main.py --cpu 1 --network yes
```

## Формат входных данных
CSV должен содержать столбцы `name,hardness,C,D,T`.
Классы: `жёсткое`, `твёрдое`, `мягкое`. Все C, D, T задаются в миллисекундах.

## Важное допущение
В методичке не дана отдельная формула для требуемого времени реакции. В этом варианте оно рассчитывается как минимальный D среди жёстких задач, а если жёстких задач нет — как минимальный D среди всех задач. Это согласуется с числовым примером методички (R_треб = 5 мс), но перед сдачей стоит уточнить у преподавателя, именно ли такую трактовку он ожидает.

Коэффициент загрузки `U = sum(C_i / T_i)`. Условие `U <= 1` — необходимое, но не достаточное условие планируемости в общем случае.

Классификация архитектуры в этом проекте: при наличии сети — распределённая; иначе при числе процессоров больше одного — многопроцессорная; в остальных случаях — однопроцессорная. Если преподаватель трактует сочетание «1 процессор + сеть» иначе, измените `classify_architecture()`.
